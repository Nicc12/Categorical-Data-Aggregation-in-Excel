# Categorical Data Aggregation in Excel
---
#### Purpose:
---
This Excel template uses strings and data input to analyze data received from categorical reports. Allowing for stakeholders to derive insights from such reports in which metrics are needed. I developed this template while working as a Data Coordinator.
---
#### Methods: 
---
This template uses a combination of math, XLOOKUP, SORTBY, and other Excel functions to derive a matrix displaying counts per any specified category
---
#### Application:
---
Although I will omit the use case from the template's original creation for privacy reasons, an example use case in the template's description tab is restaurant violations. If a corporation needs to track violations for each location based on reports submitted to the owner, to help prevent future occurrences and identify areas that need support, this template shows how simple data entry when the report is received can enable immediate analysis.
